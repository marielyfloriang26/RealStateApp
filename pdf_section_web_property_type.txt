Consideraciones  al  eliminar  un  tipo  de  propiedad  
Al  eliminar  un  tipo  de  propiedad,  el  sistema  debe  gestionar  correctamente  toda  la  
información
 
relacionada
 
con
 
las
 
propiedades
 
asociadas
 
a
 
ese
 
tipo.
 
La  eliminación  debe  incluir  o  gestionar  correctamente  los  siguientes  datos:  
●   
Elemento
 
Descripción
 
Propiedades
 
El  sistema  debe  eliminar  las  propiedades  asociadas  a  este  tipo  para  evitar  datos  huérfanos.
 
Imágenes
 
Deben  eliminarse  los  archivos  de  imagen  vinculados  a  las  propiedades  afectadas.
 
Mejoras
 
Se  deben  gestionar  las  mejoras  relacionadas  para  mantener  la  integridad  de  la  base  de  datos.
 
Ofertas
 
El  sistema  debe  remover  las  ofertas  realizadas  sobre  las  propiedades  que  serán  eliminadas.
 
Conversaciones
 
Los  mensajes  y  chats  vinculados  a  estas  propiedades  deben  gestionarse  para  evitar  inconsistencias.
 
Favoritos
 
Deben  eliminarse  las  marcas  de  favoritos  de  los  clientes  asociadas  a  las  propiedades  eliminadas.
 
La  eliminación  debe  ejecutarse  de  forma  completa  para  evitar  datos  huérfanos  o  
inconsistencias
 
en
 
la
 
base
 
de
 
datos.
