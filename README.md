Objetivo general  

Desarrollar una aplicación web para la gestión de propiedades inmobiliarias, 
utilizando ASP.NET Core MVC 9, que permita administrar de manera integral el 
registro, consulta, publicación y seguimiento de propiedades disponibles para venta o 
alquiler. El sistema debe permitir que los usuarios visitantes consulten propiedades 
disponibles, apliquen filtros de búsqueda, visualicen el detalle completo de cada 
propiedad y revisen la información de los agentes inmobiliarios asociados. 
Además, la aplicación debe permitir que los clientes registrados puedan marcar 
propiedades como favoritas, comunicarse con los agentes mediante un módulo de 
mensajería y realizar ofertas sobre propiedades disponibles. 

De igual forma, los 
agentes inmobiliarios deben poder gestionar sus propiedades, responder mensajes, 
revisar ofertas recibidas y actualizar el estado de una propiedad cuando una oferta 
sea aceptada. La plataforma también debe permitir que los administradores 
gestionen los usuarios del sistema, los agentes inmobiliarios, los desarrolladores, los 
tipos de propiedades, los tipos de ventas y las mejoras disponibles para las 
propiedades. 

Finalmente, el sistema debe incluir una API protegida mediante autenticación JWT, 
que permita consultar y administrar información clave de la aplicación según los roles 
autorizados, garantizando el control de acceso, la seguridad de los datos y la correcta 
separación de responsabilidades entre la aplicación web y los servicios expuestos.
